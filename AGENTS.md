# Autonomous Web-Novel Translation Studio — Navigation & Guardrails

- **Verification gate (`red/green`)**: Run `npm test && npx tsc --noEmit && npm run lint` after edits to `lib/`, `scripts/`, `app/`, or `components/`. Mechanical typography, punctuation (`:[ \t]*—`, `?..`, `!..`, `...`), DAG zero-cycle, client/server isolation, SQLite OCC/mirror, and auth invariants are enforced in [`lib/audit-fixes.test.ts`](lib/audit-fixes.test.ts).
- **Zero-Cycle DAG & Client/Server Boundary**: Keep [`lib/qa-linter.ts`](lib/qa-linter.ts) free of downstream `export *` re-exports. Never import server-only modules (`llm-inference-port.ts`, `pipeline-run-engine.ts`, `gemini-decision-engine.ts`, `local-embed-client.ts`, `chapter-verifier-server.ts`, `sqlite-db-server.ts`, `disk-db-server.ts`, `job-broker.ts`) into `components/`. Always load `node:sqlite` via `process.getBuiltinModule('node:sqlite')` and keep `.ts` extensions on relative imports in `lib/` and `scripts/`.
- **Database serialization & Auth**: Read and write `data/novels_db.json` exclusively via `parseDiskDatabasePayload` and `serializeDiskDatabasePayload` in [`lib/storage-idb.ts`](lib/storage-idb.ts); SQLite WAL (`data/studio.db`) is authoritative on server. When `STUDIO_API_TOKEN` is set, browser clients unlock via [`POST /api/auth`](app/api/auth/route.ts) (`studio_session` HttpOnly HMAC cookie).
