# Доменный глоссарий проекта: Автономная студия перевода веб-новелл

Настоящий документ фиксирует канонический словарь предметной области проекта, архитектурные термины и границы ответственности доменных сущностей (в соответствии с протоколом `domain-modeling`).

---

### 1. Canon Glossary (Канонический глоссарий)
- **Суть**: Единый структурированный словарь терминологии веб-новеллы по 5 категориям:
  - `realms` (Ступени культивации, ранги)
  - `characters` (Имена персонажей)
  - `sects_and_places` (Секты, павильоны, тайные царства, топонимы)
  - `system_and_terms` (Техники, артефакты, пилюли, системные окна)
  - `units` (Меры веса, длины, времени: цзинь, ли, шичень)
- **Инвариант**: Каждый термин может обладать метаданными `GlossaryTermMeta` (грамматический род `M`/`F`/`N`, указания по склонению, тональность). Гарантирует преемственность именования на дистанции сотен глав (50–500 глав).
- **Код**: [`lib/canon-glossary-vault.ts`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/canon-glossary-vault.ts), [`lib/qa-linter.ts`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts).

### 2. Scouted Term (Скаутированный кандидат в канон)
- **Суть**: Терминологическая сущность, извлечённая из текста оригинала до или во время перевода.
- **Атрибуты**: `id`, `eng` (оригинал), `rus_suggested` (предложенный перевод), `category`, `gender` (род), `chapter_first_seen`, `context_snippet`, `approved_for_glossary` (статус утверждения), `confidence` (уверенность ∈ `[0, 1]`).
- **Инвариант**: При `confidence >= autoApproveThreshold` (по умолчанию 0.92–0.95) кандидат автоматически зачисляется в `Canon Glossary` без необходимости ручного клика пользователя.
- **Код**: [`ScoutedTerm`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L45).

### 3. Addition-by-Subtraction Scout (Скаут «Сложение через вычитание»)
- **Суть**: Двухагентный алгоритм предварительного извлечения терминологии (архитектура TransAgents):
  - **Агент A (Addition / Recall)**: Извлекает максимальный пул кандидатов из исходного англоязычного текста (все сущности с заглавных букв, составные термины с ключевыми сянься-маркерами `Pill`, `Sect`, `Realm`, `Cauldron` и др.).
  - **Агент S (Subtraction / Precision)**: Агрессивно вычитает общеупотребительные английские слова, стоп-слова, местоимения и синтаксический шум.
- **Инвариант**: В канон попадают только устойчивые онимы и термины сеттинга; ложные срабатывания на общеязыковые слова («Under», «The», «Moon») исключаются.
- **Код**: [`runAdditionBySubtractionScout`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L2050).

### 4. Stop-Gate (Стоп-кран глоссария перед переводом)
- **Суть**: Контрольный барьер перед запуском пакетного перевода диапазона глав: система выполняет упреждающее сканирование (Lookahead Pre-Scout) по всем главам диапазона и открывает модальное окно на 60 секунд.
- **Инвариант**: Пользователь может в один клик утвердить или скорректировать новые онимы и роды персонажей до того, как они разойдутся по десяткам переведённых глав.
- **Код**: [`prepareGlossaryStopGateTerms`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/pipeline-run-engine.ts#L280).

### 5. DelTA Context Packet (4-уровневый пакет контекстной памяти)
- **Суть**: Контекстный пакет, собираемый перед генерацией перевода каждой главы для сохранения глобального контекста:
  1. $M^{(i)}$ — **Краткосрочное скользящее окно** (Short-Term Window): последние 3 неразделительных абзаца на ENG и RUS из предыдущей главы.
  2. $\hat{N}^{(i)}$ — **Долгосрочная память** (Long-Term Memories): релевантные реплики и предложения из ранних глав.
  3. $A_s^{(i)}, A_t^{(i)}$ — **Билингвальное резюме** (Bilingual Chapter Memory Summary): краткая сводка сюжета на русском и английском языках.
  4. $\hat{R}^{(i)}$ — **Отфильтрованный срез канона** (Chapter-Sliced Glossary): только термины, встречающиеся в текущей главе.
- **Код**: [`buildDelTAContextPacket`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L2243).

### 6. Hero State Ledger (Паспорт Героя и состояния мира)
- **Суть**: Сквозной реестр инвариантов протагониста и окружения:
  - Имя протагониста (`protagonistName`)
  - Текущая ступень и слой культивации (`cultivationRealm`)
  - Баланс ресурсов и очков (`resources`, например «Очки Истока: 120», «Духовные камни: 21»)
  - Артефакты, пилюли и небесные пламена (`artifactsAndFlames`)
  - Текущая локация (`activeLocation`)
  - Номер последней обновлённой главы (`lastUpdatedChapter`)
- **Инвариант**: Автоматически обновляется по итогам перевода каждой главы, пресекая регрессии культивации и галлюцинации баланса очков.
- **Код**: [`updateHeroStateLedgerFromChapter`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L1602).

### 7. Surgical Patch (Хирургическая точечная заплатка)
- **Суть**: Структурированная правка текста `{ search: string, replace: string, rationale: string }`, генерируемая литературным критиком на Pass 2.
- **Инвариант**: Применяется строго с обратным смещением (**reverse-offset patching**). Запрещает применение патчей при неоднозначном совпадении подстроки и блокирует любые правки, приводящие к потере числовых значений (**Numerical Preservation Guard**).
- **Код**: [`applySurgicalPatches`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L4286).

### 8. Canon Ripple (Каскадная замена канона)
- **Суть**: Механизм ретроактивной согласованности глоссария: при уточнении или изменении русского перевода термина находит и обновляет его во всех уже переведённых главах новеллы.
- **Морфологическое расширение**: Автоматически строит падежные формы (именительный, родительный, дательный, винительный, творительный, предложный) для существительных и словосочетаний («Очки Истока» → «Очков Истока» / «Очкам Истока», «Секта Каменного Демона» → «в Секте Каменных Демонов») и заменяет соответствующие косвенные падежи.
- **Код**: [`previewAndApplyCanonRipple`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/canon-glossary-vault.ts#L195).

### 10. DITING Quality Report (Оценка качества перевода DITING)
- **Суть**: Комплексная 6-мерная оценка качества переведённой главы по 100-балльной шкале:
  1. Точность передачи фактов (Accuracy)
  2. Литературная беглость (Fluency)
  3. Тональность и стиль жанра (Style)
  4. Сянься-канон и терминология (Xianxia Consistency)
  5. Целостность чисел и квантификаторов (Numerical Integrity)
  6. Адаптация идиом и метафор (Idiom Handling)
- **Код**: [`evaluateDitingQuality`](file:///c:/Users/vanya/Desktop/автономная-студия-перевода-веб-новелл/lib/qa-linter.ts#L2420).
